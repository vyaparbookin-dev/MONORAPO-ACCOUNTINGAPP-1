# 🖥️ Desktop App Setup Fix (Windows)

यह गाइड `npm install` के दौरान आने वाले एरर को ठीक करने के लिए है, खासकर जब इंस्टॉलेशन बहुत देर तक चलने के बाद `ChildProcess` या `builder-util` से संबंधित एरर के साथ फेल हो जाता है।

**समस्या:** यह एरर `better-sqlite3` जैसे नेटिव नोड मॉड्यूल के कारण आता है, जिन्हें आपके विंडोज सिस्टम पर कंपाइल होने के लिए C++ बिल्ड टूल्स की आवश्यकता होती है।

---

## 🛠️ समाधान: स्टेप-बाय-स्टेप गाइड

### स्टेप 1: Visual Studio Build Tools इंस्टॉल करें (सबसे ज़रूरी)

1.  **डाउनलोड:** Visual Studio Build Tools यहाँ से डाउनलोड करें।
2.  **इंस्टॉल:** डाउनलोड की गई `vs_BuildTools.exe` फाइल को चलाएं।
3.  **वर्कलोड चुनें:** इंस्टॉलर में, **"Desktop development with C++"** वाले बॉक्स पर टिक (✅) लगाएं।
4.  **इंस्टॉल करें:** दाईं ओर "Install" बटन पर क्लिक करें। इसमें आपके इंटरनेट की गति के आधार पर 20-40 मिनट लग सकते हैं (यह 1-2 GB का होता है)।
5.  **रीस्टार्ट:** इंस्टॉलेशन पूरा होने के बाद, अपने कंप्यूटर को **रीस्टार्ट (Restart)** करें। यह स्टेप बहुत ज़रूरी है।

---

### स्टेप 2: प्रोजेक्ट को क्लीन करके फिर से इंस्टॉल करें

कंप्यूटर रीस्टार्ट होने के बाद, अपने प्रोजेक्ट की रूट डायरेक्टरी में ये कमांड्स चलाएं:

1.  **पुरानी फाइल्स हटाएं:**
    ```powershell
    Remove-Item -Recurse -Force node_modules
    Remove-Item -Force package-lock.json
    ```

2.  **फिर से इंस्टॉल करें:**
    ```powershell
    npm install
    ```
    इस बार, बिल्ड टूल्स इंस्टॉल होने के कारण, यह बिना एरर के पूरा हो जाना चाहिए।

---

अब आप `npm run desktop` या अन्य कमांड चला सकते हैं।
